# Data Science Mini Projects

## Overview

This repository contains a collection of beginner-friendly Data Science projects developed using Python and popular data analysis libraries. Each project focuses on a different aspect of the Data Science workflow, including data analysis, data manipulation, visualization, and extracting meaningful insights from datasets.

The purpose of this repository is to strengthen practical Data Science skills through hands-on projects and real-world problem-solving.

---

## Projects

### 1. Student Grade Analyzer(project1)

A project that analyzes student performance using numerical data.

#### Key Features
- Calculate mean, median, and standard deviation
- Analyze student scores
- Identify top-performing students
- Filter students based on performance criteria
- Generate statistical summaries

#### Technologies
- Python
- NumPy

---

### 2. Grayscale Image Manipulator(project1)

A simple image processing project that demonstrates how images can be represented and manipulated using NumPy arrays.

#### Key Features
- Brightness adjustment
- Image cropping
- Horizontal and vertical flipping
- Pixel-level image manipulation
- Basic image transformations

#### Technologies
- Python
- NumPy
- Matplotlib

---

### 3. IPL Match Data Explorer(project3)

An exploratory data analysis project focused on IPL match data.

#### Key Features
- Team performance analysis
- Player statistics exploration
- Match outcome analysis
- Data visualization
- Performance comparisons

#### Technologies
- Python
- Pandas
- Matplotlib

---

### 4. Sales Performance Dashboard(project4)

A business analytics project designed to analyze sales and profit trends.

#### Key Features
- Sales analysis
- Profit analysis
- GroupBy operations
- Pivot table generation
- Business performance insights
- Data visualization

#### Technologies
- Python
- Pandas
- Matplotlib

---

### 5. E-Commerce Order Intelligence(project5)

A project that extracts customer and order insights from e-commerce datasets.

#### Key Features
- Data merging and joining
- Customer revenue analysis
- Order trend analysis
- Data reshaping
- Business intelligence reporting

#### Technologies
- Python
- Pandas
